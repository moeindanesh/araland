# بازطراحی هویت قالب‌ها — ۸ سپتامبر ۲۰۲۶

درخواست: تفاوت قالب‌ها باید در ترکیب‌بندی و کامپوننت‌ها محسوس باشد، فراتر از تعویض رنگ، عکس و گوشه‌های کارت.

## مسیر طراحی و اجرا

| قالب | هویت | شروع صفحه | خدمات | معرفی | بخش‌های تکمیلی |
| --- | --- | --- | --- | --- | --- |
| مدار / Orbit | دفتر معماری، خطوط ترسیم و فضای خالی | تیتر بزرگ و قاب عریض | فهرست پروژه با قاب‌های نامتقارن | بیانیه و عکس با تراز متفاوت | روایت‌های خطی، پرسش‌های شماره‌دار، فرم شبیه برگه پروژه |
| آرام / Bloom | شخصی، نرم و حسی | ترکیب مرکزی و تصویر ارگانیک | منوی مراقبت و قاب‌های نرم | روایت آرام با فاصله تنفس | یادداشت‌های صمیمی، پرسش‌های جدا، فرم دعوت به گفتگو |
| فردا / Forma | کارگاه و دفتر یادگیری | تابلوی ماژولار و تایپوگرافی جسور | سرفصل‌های شماره‌دار | ترکیب دفتر و همراهی | یادداشت‌های حاشیه‌ای، پرسش‌های دفترچه، فرم فصل بعد |
| تپش / Pulse | حرکت، ریتم و انرژی | عکس سینمایی و حروف درشت | ردیف‌های برنامه تمرین | بیانیه پرقدرت | قاب‌های ویدیویی، پرسش‌های خط شروع، فرم با کنتراست بالا |
| روشا / Luma | دقیق، انسانی و آرام | تصویر و چیدمان ویژه مراقبت | راهنمای خدمات | دعوت به شناخت و گفتگو | قاب‌های معرفی، پرسش‌های راهنما، فرم روشن و منظم |

هر قالب renderer مستقل برای hero، services و about دارد. بخش‌های دارای رفتار مشترک مانند فرم، منو و استوری منطق واحد و ظاهر متناسب با قالب دارند. متن منوهای پیش‌فرض متناسب با حوزه است؛ منوی تنظیم‌شده مالک عیناً حفظ می‌شود.

## معیارهای پذیرش

- هر پنج قالب در بالای صفحه و ادامه صفحه ترکیب‌بندی متفاوت داشته باشند.
- عنوان، زیرعنوان، عکس و مقصدهای ویرایشگر در خروجی حفظ شوند؛ آیتم‌ها محدود به سه مورد نباشند.
- حذف عکس، بخش خالی، تغییر ترتیب، بخش مخفی و صفحه مستقل بدون اطلاعات ساختگی کار کنند.
- نمونه‌های گالری جهت طراحی جدید را بازتاب دهند.
- عرض‌های ۱۴۴۰ و ۳۶۰/۳۹۰ بدون بریدگی متن و اسکرول افقی؛ منوی موبایل، FAQ، استوری و فرم با صفحه‌کلید بررسی شوند.
- قرارداد API، مجوزها، snapshot انتشار و تفکیک فرم‌ها و مقاله‌های زنده تغییر نکنند.
- اجرای db:generate، db:deploy، typecheck، test و build و ثبت نتیجه واقعی.

## نتیجه بررسی

اجرا و بررسی تکمیل شد. پنج renderer مستقل برای بخش‌های اصلی، هویت تکمیلی استوری/نظرات/پرسش‌ها/فرم/بلاگ/گالری اجتماعی، منو و footer و پنج پیش‌نمایش کوچک اختصاصی پیاده شدند. renderer قدیمی NicheHero حذف شد. رنگ پیش‌فرض فردا به بنفش تغییر کرد؛ رنگ برند ذخیره‌شده سایت‌های موجود بازنویسی نشد.

| بررسی | نتیجه |
| --- | --- |
| `bun run db:generate` | موفق |
| `bun run db:deploy` | موفق؛ migration معوق وجود نداشت |
| `bun run typecheck` | همه workspaceها موفق |
| `bun run test` | ۳۷ تست موفق: ۲۵ API و ۱۲ وب |
| `bun run build` | production build و prerender هر پنج پیش‌نمایش موفق |
| مرورگر production | هر پنج قالب در عرض‌های ۱۴۴۰، ۳۹۰ و ۳۶۰؛ بدون سرریز افقی، عکس خراب یا خطای JavaScript |
| صفحه‌کلید | منوی موبایل با Enter، فوکوس اولین لینک، Escape و بازگشت فوکوس؛ FAQ با Enter/Space؛ استوری با Tab/Shift+Tab/Escape؛ تکمیل و ارسال فرم پیش‌نمایش با صفحه‌کلید |
| محتوای ویرایش‌شده | هر پنج قالب: عنوان فارسی بلند، هفت خدمت، حذف عکس hero/services/about، حفظ آیتم‌ها و CTA؛ رفت‌وبرگشت واقعی به صفحه مستقل با slug جدید و شناسه ثابت |
| منوها | برچسب‌های سفارشی و footer صریحاً خالی حفظ شدند؛ CTA صفحه داخلی به شناسه ویرایش‌شده بخش تماس صفحه اصلی برمی‌گردد |
| بلاگ و گالری اجتماعی | هر پنج هویت با پنج آیتم در عرض‌های ۱۴۴۰ و ۳۶۰، بدون بریدگی متن یا سرریز |
| گالری انتخاب قالب | عرض‌های ۱۴۴۰ و ۳۶۰، هر پنج عکس بارگذاری شدند؛ قاب‌بندی و بازکردن پیش‌نمایش با Enter موفق |

بازبینی مستقل کد و ۲۴ حالت رندر مدار/آرام نیز انجام شد. موارد کشف‌شده و اصلاح‌شده: حفظ لینک پیش‌فرض تماس در ردیف‌های خدمات فردا، کنتراست فوکوس در سطوح تیره/روشن و دسترس‌پذیرماندن ابتدای ردیف استوری آرام با تعداد زیاد آیتم.

## تصاویر و شواهد

تصاویر Unsplash قدیمی در این محیط با خطای اتصال مواجه شدند. یازده تصویر مفهومی جدید با ابزار داخلی **ImageGen** تولید، بررسی و با Sharp به WebP تبدیل شدند. با دو تصویر موجود تپش/روشا، هر ۱۳ دارایی پیش‌فرض قالب اکنون در `apps/web/public/images/templates/` محلی‌اند؛ حجم مجموع حدود ۲ مگابایت است. دادهٔ ذخیره‌شده سایت‌های قبلی و عکس‌های سفارشی دست‌نخورده‌اند.

مسیر تک‌تک تصاویر، پرامپت‌های دقیق، روش تولید و ابعاد در [تصاویر اصلی و دو مکمل](TEMPLATE-IMAGE-PROMPTS.md) و [شش تصویر تکمیلی](TEMPLATE-SUPPLEMENTAL-IMAGES.md) ثبت شده‌اند. تمام متن‌ها و CTAها همچنان HTML و قابل ویرایش‌اند.

شواهد محلی در `output/playwright/` (خروجی آزمون، خارج از Git):

- `gallery-1440-final.png` و `gallery-360-final.png` برای گالری نهایی.
- `{orbit,bloom,forma,pulse,luma}-desktop.png` و `*-phone.png` برای هر قالب.
- `*-services.png` و `*-about.png` برای بررسی ترکیب‌بندی بخش‌ها.
- `identity-production-check-log.txt`، `identity-social-check-log.txt` و `identity-build-log.txt` برای نتیجه اجرا.

نسخه production محلی برای بازبینی: [گالری قالب‌ها](http://localhost:3101/?view=templates).

## اصلاح هیروی تپش

تصویر هیروی آغازین تپش تمام عرض و ارتفاع قاب اول را می‌پوشاند؛ منو، عنوان و دکمه‌ها روی عکس قرار می‌گیرند. ارتفاع واقعی منو و نوار پیش‌نمایش در اندازه‌گیری لحاظ می‌شود. در گوشی، برش تصویر و گرادیان برای نمایش سوژه و خوانایی متن تنظیم شده‌اند. عنوان بلند اجازه افزایش ارتفاع دارد؛ حذف عکس، جابه‌جایی یا مخفی‌کردن هیرو و صفحه‌های مستقل چیدمان عادی خود را حفظ می‌کنند.

نسخه production در عرض‌های ۱۴۴۰، ۳۹۰ و ۳۶۰ و حالت‌های ویرایشگر بررسی شد؛ سرریز افقی و خطای JavaScript مشاهده نشد. منوی موبایل با Enter/Escape و دکمه اصلی با صفحه‌کلید کار می‌کنند. تمام فرمان‌های بررسی بالا دوباره موفق شدند. شواهد: `pulse-fullscreen-{1440,390,360}.png`، `pulse-fullscreen-check.txt` و `pulse-fullscreen-edge-log.txt` در `output/playwright/`.
