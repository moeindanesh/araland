# بررسی قابلیت سایت چندصفحه‌ای

تاریخ: ۸ سپتامبر ۲۰۲۶

این گزارش مربوط به اجرای [برنامهٔ چندصفحه‌ای](MULTI-PAGE-PLAN.md) در محیط توسعه است.

## بررسی‌های خودکار

| بررسی | نتیجه |
| --- | --- |
| `bun run db:generate` | موفق |
| `bun run db:deploy` روی پایگاه‌دادهٔ موجود | خطای قبلی `P3005`: جدول‌ها وجود دارند ولی تاریخچهٔ migration ثبت نشده است. ساختار یا تاریخچهٔ دادهٔ کاربر تغییر داده نشد. |
| `bun run db:deploy` در schema موقت و مستقل | هر سه migration با موفقیت اعمال شدند؛ همان schema پس از آزمون پاک و حذف آن تأیید شد. |
| `bun run typecheck` | همهٔ بسته‌ها موفق |
| `bun run test` | ۳۱ آزمون، ۲۴۰ assertion، بدون شکست: ۲۱ آزمون API و ۱۰ آزمون لینک‌ها و proxy وب |
| آزمون API روی schema تازه migrate‌شده | ۲۱ آزمون، ۲۱۳ assertion، بدون شکست |
| `bun run build` | موفق؛ مسیر مستقل `/s/[slug]/[pageSlug]` در خروجی ثبت شد. |
| `bun run mobile:export` | خروجی Hermes برای iOS و Android موفق؛ آزمون روی دستگاه انجام نشده است. |

آزمون‌های لینک و proxy وب به دستور اصلی `bun run test` اضافه شده‌اند تا در بررسی‌های بعدی مخزن نیز اجرا شوند.

## رفتارهای بررسی‌شده

- جداسازی مالک‌ها و نشست مخاطب، نام و آدرس تکراری/رزروشده، عنوان و برچسب خالی، مقصد نامعتبر، لینک به صفحهٔ سایت دیگر و محدودیت تعداد صفحه‌ها و منوها.
- ذخیرهٔ صفحه و SEO و منو در پیش‌نویس بدون تغییر عمومی؛ انتشار مجموعه در یک snapshot؛ تغییر slug با حفظ لینک مبتنی بر شناسه و ۴۰۴شدن آدرس قدیمی.
- حذف صفحه با پاک‌سازی ارجاع‌های وابسته، غیرفعال‌کردن صفحه پس از انتشار، حذف محتوای صفحهٔ غیرفعال از پاسخ عمومی و حفظ صفحه‌های اضافه هنگام تغییر قالب.
- لینک‌های صفحه، بخش اصلی و منوی صریحاً خالی؛ حفظ منوی خودکار سایت قدیمی؛ مسیر تمیز روی دامنهٔ تأییدشده و جلوگیری از دسترسی به سایت دیگر از آن دامنه.
- HTML عمومی، عنوان/H1/توضیح/canonical صفحه، منوی مشترک صفحهٔ اصلی/صفحهٔ مستقل/مقاله و ۴۰۴ صفحهٔ غیرفعال با درخواست HTTP بررسی شدند. آزمون Host در محیط محلی است و به معنی تنظیم DNS یا TLS عمومی نیست.

## مرورگر و رابط

Playwright در مرورگر واقعی با عرض ۱۴۴۰ و ۳۶۰ اجرا شد. صفحهٔ عمومی و پنل صفحه‌ها در این عرض‌ها سرریز افقی نداشتند. ساخت صفحه، تنظیم SEO، انتخاب مقصد منو با صفحه‌کلید، ذخیرهٔ پیش‌نویس نمونه، ویرایش محتوای صفحهٔ مستقل و ساخت صفحه در عرض گوشی بررسی شدند. ساخت صفحه از کارت خدمت با انتقال عنوان و ثبت `pageId` روی همان کارت تأیید شد؛ کلیک بازگشت به خانه در پیش‌نمایش، انتخاب صفحه در ویرایشگر را هم به خانه برمی‌گرداند. منوی عمومی گوشی با Enter باز می‌شود، فوکوس به اولین لینک می‌رود و Escape آن را می‌بندد و فوکوس را به دکمه بازمی‌گرداند.

در بررسی، لینک بی‌نام بخش اصلی صفحهٔ تازه، ناهماهنگی صفحهٔ پیش‌نمایش و انتخاب ویرایشگر، تغییر ناخواستهٔ منوی قدیمی هنگام سفارشی‌سازی، عنوان بیش‌ازحد بلند هنگام ساخت صفحه از کارت و تشخیص Host در proxy اصلاح شدند.

## محدودیت‌های باقی‌مانده

آزمون تعاملی اپ روی دستگاه واقعی، DNS/TLS عمومی، انتشار مستقل هر صفحه، صفحه و منوی تو‌در‌تو، redirect آدرس قدیمی و کنترل تعارض ویرایش هم‌زمان در این تحویل انجام نشده‌اند. داده‌های آزمایشی سرور و schema موقت جدا از داده‌های کاربر ساخته و پاک شدند.
