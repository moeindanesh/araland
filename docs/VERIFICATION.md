# گزارش بررسی نسخه اولیه

تاریخ: ۶ سپتامبر ۲۰۲۶. محیط: macOS، Bun 1.3.0، Node 24، PostgreSQL 17 محلی روی پورت 55432.

## نتیجه بررسی‌های خودکار

| بررسی | نتیجه |
| --- | --- |
| نصب dependency با lockfile | موفق |
| Prisma generate و اعمال migration | موفق؛ سه migration اعمال‌شده، مورد معوق ندارد |
| Typecheck همه پنج workspace | موفق؛ web پیش از بررسی route type تولید می‌کند |
| تست یکپارچه API | ۱۸ تست موفق، ۰ خطا، ۱۳۷ assertion روی PostgreSQL واقعی |
| Next.js production build | موفق؛ هر سه پیش‌نمایش ساخته می‌شوند و سایت/مقاله عمومی server-rendered هستند |
| Expo compatibility | نسخه‌های وابستگی با SDK 57 سازگارند |
| Native export | iOS و Android موفق؛ bundleهای Hermes هرکدام حدود 4.2 MB |
| CI | workflow برای اجرای بررسی‌ها نوشته شد؛ اجرای خارجی GitHub Actions انجام نشده است |

آزمون‌های API شامل OTP هش‌شده، محدودیت تلاش و انقضا، مصرف هم‌زمان و عدم replay، جداسازی مالک‌ها، پیش‌نویس و snapshot انتشار همراه SEO و قالب، فیلدهای فرم و داده‌های نامعتبر، snapshot عنوان فیلد پس از ویرایش/حذف فرم، وضعیت انتشار مقاله، دسترسی گیرنده فایل و مالک، تبدیل تصویر با sharp، رد SVG، عدم مسیریابی دامنه تاییدنشده، CORS دامنه تاییدشده و وضعیت سرویس AI بدون اعتبار هستند. تست‌های محدوده نشست همچنین ثابت می‌کنند ورود از دامنه مشتری نشست مخصوص همان سایت می‌سازد، کد مدیر در آن دامنه قابل مصرف نیست، نشست مخاطب نمی‌تواند سایت بسازد/مدیریت کند یا فایل و پنل سایت دیگر را بخواند. تست‌ها داده‌های اختصاصی خود را پاک می‌کنند و به سرویس پولی وصل نمی‌شوند.

## بررسی تعاملی وب

در مرورگر واقعی انجام شد:

- مشاهده داشبورد نمونه و برچسب آمار نمایشی؛ بعد از ورود جایگزینی با داده‌های واقعی.
- دریافت OTP تصادفی توسعه برای حساب seed و ورود به حساب.
- ساخت یک سایت مستقل با قالب Bloom؛ ویرایش عنوان hero و ذخیره؛ نمایش تغییر در iframe پیش‌نمایش.
- انتشار و مشاهده همان عنوان در صفحه عمومی رندرشده.
- پرکردن فرم عمومی، مشاهده تایید ثبت، بازکردن داشبورد مخاطبان و مشاهده همان پاسخ.
- سایت و پاسخ موقت این بررسی پس از اتمام حذف شدند؛ seed دست‌نخورده ماند.
- مشاهده طراحی Orbit، Bloom و Forma در دسکتاپ و موبایل. اندازه‌گیری در عرض‌های 360، 390، 768 و 1280 برای هر سه قالب، بدون عنصر بیرون‌زده از صفحه.
- پنجره‌ها: فوکوس اولیه، Tab و Shift+Tab، Escape، جلوگیری از خروج فوکوس، بازگشت فوکوس به بازکننده و آزادشدن اسکرول.
- استوری با/بدون CTA: دیالوگ قابل دسترس، رفتار کیبورد، بستن و رفتن به بخش دارای شناسه سفارشی.
- منوی موبایل: aria-expanded، Escape و بازگشت فوکوس.
- لینک‌های خدمات/ارتباط بعد از تغییر شناسه بخش؛ متن سفارشی CTA درباره‌ما؛ عدم نمایش tagline پیش‌نویس در نسخه عمومی.

اصلاحات حاصل از بررسی: حذف نمودارهای نمونه از حساب واقعی، عنوان درست بازه آمار، جلوگیری از نمایش اطلاعات سایت قبلی، مقدار کامل TXT، URLهای اختیاری خالی، ویرایش و انتشار draft مقاله، دسترسی به پایین sidebar، کنترل فوکوس، رفع overflow تصویر Forma و حذف نظرات/تصاویر کاربران نمونه از شروع واقعی کسب‌وکار.

## مواردی که هنوز تایید عملیاتی نشده‌اند

- پیامک واقعی کاوه‌نگار و تولید تصویر پولی OpenAI: اتصال‌ها پیاده شده‌اند، حساب/اعتبار تنظیم نشده است.
- DNS یک دامنه واقعی، گواهی HTTPS و سرویس عمومی: نیاز به زیرساخت و دامنه دارد.
- اجرای تعاملی اپ روی دستگاه: export و typecheck موفق‌اند، اما تست دستگاه، build امضاشده و انتشار فروشگاهی انجام نشده‌اند. تلاش برای دسترسی به Simulator از سطح فعال کنترل رایانه موفق نبود؛ بنابراین ادعای تست بومی تعاملی نداریم.
- بارگذاری و دریافت فایل و دسترسی بین کاربران در تست API تایید شده‌اند؛ سناریوی کامل آن‌ها در UI دستگاه اجرا نشده است.
- مقیاس چندسروری، بار زیاد، پشتیبان‌گیری/بازیابی، اسکن فایل، پرداخت، صف و سهمیه AI و مانیتورینگ عملیاتی در نقشه راه‌اند.

منابع خارجی تصاویر ممکن است به اینترنت نیاز داشته باشند. جایگزینی با رسانه بارگذاری‌شده امکان‌پذیر است. جزئیات منبع و مجوز فونت در ASSETS.md ثبت شده‌اند.

## به‌روزرسانی HeroUI و فونت — ۶ سپتامبر ۲۰۲۶

- پنل، ورود و ویرایشگر از HeroUI 3.2.4 استفاده می‌کنند: Button، Input، TextArea، Select/ListBox، Checkbox، Tabs، Accordion، Card، Spinner و Modal. انتخاب فایل با ورودی بومی مرورگر انجام می‌شود. رنگ‌بندی و چیدمان قبلی طبق انتخاب کاربر حفظ شده‌اند.
- فونت پنل IRANYekanXFaNum محلی است؛ هر شش WOFF2 با فایل اصلی بسته کاربر تطبیق باینری دارند. مرورگر بارگذاری وزن‌ها را تأیید کرد؛ ورودی‌ها و پنجره‌های منتقل‌شده به portal نیز همین فونت را دارند. فونت قالب‌های عمومی مستقل و Vazirmatn باقی مانده است.
- ورود با کد توسعه و ساخت سایت اختصاصی آزمون از رابط انجام شد. فرم تازه با نوع فیلد انتخابی ساخته شد؛ گزینه‌ها با ویرگول فارسی ذخیره شدند. Checkbox با Space و انتخاب‌گر با End/Enter کار کرد.
- محصوربودن فوکوس برای ۲۰ بار Tab، بستن Modal با Escape و بازگشت فوکوس به دکمه بازکننده بررسی شد. تب‌های مخاطبان و ویرایشگر با جهت‌نماهای چپ/راست در RTL بررسی شدند.
- عنوان صفحه در ویرایشگر تغییر کرد، ذخیره و منتشر شد و همان عنوان در API عمومی و صفحه عمومی دیده شد. فرم عمومی پاسخ ثبت کرد و همان پاسخ در پنل دیده شد؛ جستجوی شماره با ارقام فارسی نتیجه صحیح داد.
- مقاله بدون جلد ساخته و منتشر شد؛ ویرایش آن نیز ذخیره شد. در آزمون درخواست معطل‌شده، ورودی عنوان، Checkbox انتشار و دکمه ذخیره غیرفعال بودند؛ با آزاد شدن درخواست، تغییرات صحیح باقی ماندند. Spinner نام دسترس‌پذیر دکمه را تغییر نمی‌دهد.
- فایل متنی اختصاصی آزمون از UI بارگذاری و توسط مالک دریافت شد؛ فایل خروجی با ورودی تطبیق باینری داشت. کنترل دسترسی میان کاربران همچنان با آزمون‌های API بررسی می‌شود.
- اصلاحات اضافی: جلوگیری از درخواست تکراری ورود، خطا/تلاش دوباره فهرست‌ها، حالت روشن حساب بدون سایت، جلوگیری از ویرایش هنگام ذخیره، نرمال‌سازی جستجوی شماره فارسی/عربی، تأیید تغییر قالب و خروج با ویرایش ذخیره‌نشده.
- `db:generate`، `db:deploy`، typecheck، ۱۸ آزمون API با ۱۳۷ assertion و production build موفق بودند. تغییر schema یا migration تازه‌ای لازم نبود.

موبایل از چهار TTF اصلی همان بسته و وزن‌های واقعی استفاده می‌کند. Typecheck و export اندروید و iOS موفق‌اند. تصویر اجرای اولیه در شبیه‌ساز iPhone، نمایش فونت در ورود و داشبورد را تأیید کرد. بازخوانی محیط توسعه Expo Go با خطای `Cannot find native module 'ExpoAsset'` روبه‌رو شده است؛ اجرای تعاملی کامل و دستگاه واقعی اندروید/iOS هنوز تأیید نشده‌اند. جزئیات قابل بازتولید در [وضعیت موبایل](../apps/mobile/STATUS.md) ثبت شده‌اند.

در بازبینی HeroUI، هر ۹ بخش پنل در عرض‌های ۳۶۰، ۳۹۰ و ۱۴۴۰ بررسی شدند: ۲۷ ترکیب بدون اسکرول افقی صفحه و بدون استثنای JavaScript. ویرایشگر در ۳۶۰ و ۱۴۴۰ و پنجره فرم‌ساز در ۳۹۰ نیز بررسی تصویری شدند. تصاویر بررسی محلی در `output/playwright` قرار دارند و در Git ثبت نمی‌شوند.

انتخاب بین دو سایت با Select جدید و کیبورد بررسی شد. منوی موبایل با ۲۲ بار Tab، پنجره راهنمای روی آن با ۸ بار Tab و بستن پیاپی با Escape بررسی شد؛ پس از بازگشت فوکوس از پنجره به منو، بستن منو فوکوس را به بازکننده بازمی‌گرداند. منوی بسته از فوکوس و درخت دسترس‌پذیری خارج است. نسخه production نیز روی پورت جدا اجرا شد و پنجره، فونت و چیدمان در عرض ۳۹۰ و ۱۴۴۰ بررسی شدند.

پس از بررسی، دو سایت اختصاصی QA، پاسخ، مقاله و فایل خصوصی آن‌ها و حساب ساخته‌شده در همان آزمون پاک شدند؛ سایت seed حفظ شد. پس از حذف سایت‌های QA و پیش از حذف حساب، حالت حساب بدون سایت نیز در UI بررسی شد: با بستن پنجره ساخت، فقط دعوت به ساخت اولین سایت دیده می‌شد و آمار/سایت نمونه نمایش داده نمی‌شد.

## بازبینی کامل مسیرهای پنل — ۶ سپتامبر ۲۰۲۶

[گزارش UX/UI](UX-AUDIT.md) اصلاحات و شواهد هر مسیر را ثبت می‌کند. راهنمای قدم بعدی از وضعیت واقعی سایت استفاده می‌کند؛ آمار بارگذاری/خطا با صفر اشتباه نمی‌شود؛ تغییرات ذخیره‌نشده در تعویض بخش، Back و تعویض سایت محافظت می‌شوند. پیش‌نمایش، فرم‌ها و نوشته‌های واقعی را نشان می‌دهد و آمادگی iframe پیش از ارسال اطلاعات هماهنگ می‌شود.

مسیر ساخت سایت، ویرایش، شکست و بازیابی انتشار، فرم عمومی و مشاهده پاسخ، CSV، انتشار نوشته، بهینه‌سازی تصویر و ذخیره در پیش‌نویس در مرورگر گذشت. فایل خصوصی هم از حساب مالک و هم با ورود اختصاصی مخاطب دریافت و با اصل تطبیق باینری شد. سه بار بازکردن مستقل ویرایشگر، دریافت نوشته منتشرشده در پیش‌نمایش را تایید کرد. تغییر قالب و ذخیره تصویر، snapshot عمومی را تغییر ندادند.

۲۷ ترکیب از ۹ بخش در عرض‌های ۳۶۰، ۳۹۰ و ۱۴۴۰ پس از آخرین تغییرات، بدون اسکرول افقی و با آیتم‌های تمام‌عرض سایدبار بررسی شدند. منو با ۲۴ بار Tab، راهنمای روی آن با ۱۲ بار Tab، Escape و بازگشت فوکوس بررسی شد. Checkbox با Space، انتخاب‌گر با Home/End و Enter و نتیجه دوم جستجو با Tab/Enter کار کرد. آزمون UI انقضای کد، محدودیت ارسال پس از ویرایش شماره و قطع شبکه با ساعت/پاسخ کنترل‌شده مرورگر انجام شد.

Prisma generate/deploy، typecheck پنج workspace، ۱۸ تست با ۱۳۷ assertion و production build موفق بودند. اجرای production روی IPv4 محلی در عرض‌های ۱۴۴۰ و ۳۹۰، بدون خطای JavaScript و با فونت IRANYekanXFaNum در پنجره راهنما تایید شد. اپ بومی در این بازبینی تغییر نکرد.

دو سایت و دو حساب اختصاصی این بازبینی، سه فرم، یک پاسخ، یک نوشته، دامنه آزمایشی `.invalid` و فایل و تصویر موقت پاک شدند؛ دو فایل فیزیکی مربوط هم حذف شدند. سایت seed پیش و پس از پاک‌سازی مقایسه و حفظ شد. پیامک واقعی، AI دارای اعتبار و DNS/HTTPS عمومی آزمون عملیاتی نشده‌اند.
