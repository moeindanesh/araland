# اپ مدیریت آرالند

اپ بومی فارسی با **Expo SDK 57، React Native 0.86.3 و HeroUI Native 1.0.9**. دکمه‌ها، کارت‌ها و provider از HeroUI Native واقعی هستند؛ استایل آن با Uniwind و Tailwind 4 تنظیم شده است. فونت **IRANYekanX با اعداد فارسی** از بسته ارائه‌شده کاربر، با چهار فایل اصلی TTF در وزن‌های Regular، Medium، DemiBold و Bold، داخل اپ قرار دارد و به اینترنت نیاز ندارد. متن‌ها، ورودی‌ها و عنوان دکمه‌های HeroUI از همین وزن‌های واقعی استفاده می‌کنند؛ نگاشت آن‌ها در `src/typography.tsx` و `global.css` است. فایل توضیح مجوز همراه فونت در `assets/fonts/FontLicense.txt` بدون تغییر حفظ شده است.

## اجرا

از ریشه مونوریپو وابستگی‌ها را نصب و API و PostgreSQL را راه‌اندازی کنید. سپس:

```sh
cp apps/mobile/.env.example apps/mobile/.env
bun run dev:mobile
```

کد QR را در **Expo Go سازگار با SDK 57** باز کنید، یا از داخل Expo کلید `i` برای شبیه‌ساز iOS و `a` برای Android را بزنید. این اپ برای iOS/Android است؛ برای مدیریت از مرورگر از `apps/web` استفاده کنید.

روی گوشی واقعی، `localhost` به خود گوشی اشاره می‌کند. در `apps/mobile/.env` آدرس LAN رایانه یا دامنه HTTPS سرور را تنظیم کنید:

```dotenv
EXPO_PUBLIC_API_URL=http://192.168.1.10:4000/api
EXPO_PUBLIC_WEB_URL=http://192.168.1.10:3000
```

گوشی و رایانه باید در یک شبکه باشند و پورت‌ها در دسترس باشند. در محیط سرور نیز `API_PUBLIC_URL=http://192.168.1.10:4000` را تنظیم کنید تا نشانی تصویرهای آپلودشده برای گوشی قابل دریافت باشد. برای Android Emulator معمولاً نشانی میزبان `10.0.2.2` است. پس از تغییر متغیرهای Expo، bundler را دوباره اجرا کنید. برای نسخه قابل انتشار از HTTPS معتبر استفاده کنید.

## امکانات پیاده‌سازی‌شده

- ورود با OTP و ذخیره توکن در Keychain/Keystore از طریق SecureStore؛ کد آزمایشی فقط زمانی نمایش داده می‌شود که API با `AUTH_DEV_MODE=true` آن را برگرداند.
- ساخت چند سایت، انتخاب سایت، پنج قالب (از جمله تپش ورزشی و روشا پزشکی) و انتشار مستقل از پیش‌نویس.
- آمار واقعی API و وضعیت خالی/خطا/در حال دریافت؛ هیچ آمار ساختگی در اپ وجود ندارد.
- تغییر نام و رنگ برند، افزودن/حذف/ویرایش/مرتب‌سازی/نمایش یا پنهان‌کردن بخش‌ها؛ ویرایش آیتم‌های خدمات، سوالات، استوری و پیوند پست اینستاگرام.
- ساخت چند صفحهٔ عمومی، خدمت و موضوع در تب «سایت من»؛ انتخاب صفحه برای ویرایش بخش‌ها، عنوان، آدرس، SEO و فعال‌بودن مستقل. قالب و برند در همهٔ صفحه‌ها مشترک‌اند.
- تعیین محل و ترتیب پیوندها در منوهای بالای سایت و پایین سایت؛ اتصال به صفحهٔ اصلی، صفحهٔ داخلی، بخش صفحهٔ اصلی یا نشانی دلخواه. کارت خدمت/استوری و دکمهٔ اصلی می‌توانند از فهرست صفحه‌ها مقصد انتخاب کنند؛ از هر کارت نیز می‌توان صفحهٔ خدمت یا موضوع ساخت.
- آپلود و بهینه‌سازی تصویر اصلی، درباره ما، خدمات و استوری‌ها؛ تولید تصویر با adapter واقعی AI سرور.
- ساخت و ویرایش فرم با پنج نوع فیلد و گزینه‌های الزامی، جستجوی پاسخ فرم و اعضای سایت.
- ساخت، ویرایش، انتشار و حذف نوشته بلاگ، تنظیمات SEO و نام سایت.
- ثبت دامنه، نمایش دقیق رکورد TXT برای بررسی مالکیت و حذف اتصال با تأیید.
- ارسال فایل خصوصی برای شماره مخاطب، دریافت فایل با توکن مجاز، بازکردن پنجره اشتراک‌گذاری دستگاه و حذف/لغو دسترسی با تأیید.

پیش‌نویس همهٔ صفحه‌ها و منوها با دکمهٔ ذخیره ثبت می‌شود؛ جابه‌جایی بین صفحه‌ها تغییرات ثبت‌نشده را حفظ می‌کند. خروج از تب ویرایش یا تغییر سایت هنگام وجود تغییرات ثبت‌نشده هشدار می‌دهد. انتشار، پیش‌نویس کل سایت را ابتدا ذخیره و سپس منتشر می‌کند. حذف صفحه، پیوندهای داخلی وابسته را از پیش‌نویس پاک می‌کند؛ صفحهٔ غیرفعال بعد از انتشار از سایت عمومی پنهان می‌شود. پیوندهایی که از فهرست صفحه‌ها انتخاب شده‌اند با شناسهٔ ثابت ذخیره می‌شوند و تغییر آدرس صفحه را دنبال می‌کنند، اما آدرس قدیمی پس از انتشار دیگر باز نمی‌شود. تغییر قالب صفحه‌های اضافه را حفظ می‌کند و فقط محتوای اولیهٔ صفحهٔ اصلی را بازنشانی می‌کند. ساخت/حذف فرم‌ها و مقالات مستقل از snapshot سایت است؛ نوشته فقط با گزینه «انتشار» عمومی می‌شود.

در ۸ سپتامبر ۲۰۲۶ بررسی TypeScript و export هر دو پلتفرم پس از افزودن مدیریت چندصفحه‌ای، دو قالب و کنترل‌های حذف فایل/دامنه موفق بود. تصویرهای همراه قالب از مبدأ `EXPO_PUBLIC_WEB_URL` بارگذاری می‌شوند. تعاملات جدید روی دستگاه یا شبیه‌ساز اجرا نشده‌اند؛ نتیجهٔ export به‌تنهایی تأیید این تعاملات نیست.

در همین روز شروع اپ و راه‌اندازی دوباره process در Expo Go 57.0.9 / iPhone 16 Pro / iOS 18.5 نیز صفحه آغاز و فونت را نمایش دادند؛ خطای ExpoAsset در این دو شروع دیده نشد. پنجره معرفی Expo Go و نبود دسترسی Simulator در ابزار کنترل رابط، مانع آزمون تعاملی اکشن‌ها شد. این مشاهده به معنای رفع قطعی مشکل reload پیشین یا تأیید کل جریان اپ نیست. تصاویر در `output/playwright/audit-native-start.png` و `audit-native-restart.png` ثبت شده‌اند.

## بررسی

```sh
bun run --filter @araland/mobile typecheck
bun run --filter @araland/mobile export
```

Typecheck با TypeScript 6 و تولید بسته Hermes برای **هر دو پلتفرم** پس از تغییر فونت در ۶ سپتامبر ۲۰۲۶ موفق بودند؛ هر چهار فایل TTF در خروجی export ثبت شدند. خروجی در `apps/mobile/dist` ایجاد می‌شود و یک فایل قابل نصب IPA/APK نیست. برای انتشار فروشگاهی به development build / EAS، امضای برنامه و حساب فروشگاه نیاز است.

اجرای واقعی نیز با Expo Go 57.0.9 روی شبیه‌ساز iPhone 16 Pro / iOS 18.5 بررسی شد: اپ و فونت در صفحه ورود و داشبورد بارگذاری شدند و نشست ذخیره‌شده بازیابی شد. پس از راه‌اندازی مجدد میزبان و بازسازی کش Metro، شروع برنامه موفق بود؛ اما با بازخوانی بعدی محیط توسعه خطای `Cannot find native module 'ExpoAsset'` دوباره دیده شد. تغییر آزمایشی ترتیب import هم این خطا را رفع نکرد و نگه داشته نشد. دستور استفاده‌شده در این محیط: `NODE_OPTIONS=--dns-result-order=ipv4first bun run --filter @araland/mobile start --localhost --clear`. گزینه IPv4 فقط مشکل اتصال manifest به سروری را رفع می‌کند که `localhost` آن فقط روی IPv6 گوش می‌دهد؛ خطای بازخوانی میزبان هنوز حل نشده است.

این بررسی، اجرای موفق و مشاهده فونت در شبیه‌ساز را تأیید می‌کند. شبیه‌ساز در ابزار کنترل رابط قابل دسترسی نبود و پنجره معرفی Expo Go بخشی از صفحه را پوشانده بود؛ بنابراین تعاملات کامل، صفحه‌کلید، دسترس‌پذیری، دستگاه واقعی و Android runtime همچنان آزموده نشده‌اند.
